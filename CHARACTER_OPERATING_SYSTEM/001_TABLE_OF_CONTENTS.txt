=== SECTION: FILE_MANIFEST ===

[[LLM_INSTRUCTION]]: MODULE_ID is the stable canonical key. LOAD_ORDINAL is a presentational load attribute only. Identity references use MODULE_ID; load operations use LOAD_ORDINAL. The ordinal range is gap-free except for one declared suffix.

CANONICAL_FILE_COUNT: 70
LAST_LOAD_ORDINAL: 069
ORDINAL_CONTINUITY: CONTIGUOUS_WITH_SUFFIX
LAWFUL_NON_NUMERIC_ORDINALS:
- 002A

MANIFEST_RULES:
- CANONICAL_FILE_COUNT is the authoritative module total.
- LAST_LOAD_ORDINAL is the final load position and is not the file count.
- The numeric sequence 001 through 069 is gap-free; the only lawful deviation is the declared 002A suffix.
- A suffixed ordinal is lawful when declared in LAWFUL_NON_NUMERIC_ORDINALS or implied by CONTIGUOUS_WITH_SUFFIX continuity.
- CONTIGUOUS_WITH_SUFFIX means tooling must not flag a missing number; it must instead expect each declared suffix in LAWFUL_NON_NUMERIC_ORDINALS.
- Tooling reads CANONICAL_FILE_COUNT for totals and MODULE_ID for identity; it must not infer either from LAST_LOAD_ORDINAL.
- Every MODULE_ID with a CANONICAL_MODULE_ROOTS counterpart must match CANONICAL_TOKEN_DICTIONARY.CANONICAL_MODULE_ROOTS exactly.

=== SECTION: LOAD_ORDER_VS_EXECUTION_ORDER ===

DROP_ORDER:
- LOAD_ORDINAL 001 through 069, including 002A, is session load order.
- Persistent layers remain loaded across cycles.
- Scratchpad structure is loaded once; scratchpad instance resets per cycle.

EXECUTION_ORDER:
- Per-cycle execution is exclusively UPDATE_CASCADE_REGISTRY.EXECUTION_ORDER_PRIORITY.
- Governance slots:
  - PRIORITY_16: STATE_GOVERNANCE_AND_COMMIT_PRIMARY_PASS
  - PRIORITY_17: COT_UPDATE_VERIFICATION
  - PRIORITY_18: STATE_GOVERNANCE_AND_COMMIT_POST_VERIFICATION_PASS
- Post-verification commit is a restricted second invocation of STATE_GOVERNANCE_AND_COMMIT, not another file or writer.

VOLATILE_AND_GOVERNANCE_SIGNAL:
- COGNITIVE_SCRATCHPAD resets each cycle and is wiped after PRIORITY_18.
- STATE_GOVERNANCE_RUNTIME is the sole persistent cross-cycle governance signal.
- Verification/quarantine updates reach STATE_GOVERNANCE_RUNTIME only through post-verification commit.
