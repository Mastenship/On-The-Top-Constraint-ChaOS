=== SECTION: MEMORY_EVALUATION ===

[[LLM_INSTRUCTION]]: Apply DYNAMICS_MEMORY.MEMORY_ADMISSION_GATE.

SALience_EVALUATION:
- Estimate SALIENCE from cue intensity, novelty, consequence, linkage relevance, and emotional load.
- Emotional arousal raises salience only when consequence or linkage exists.
- Flashbulb treatment requires DYNAMICS_MEMORY.FLASHBULB_GATE.

FORMATION_DECISION:
- If admission gate passes:
  - PROPOSE SET pair:
    - [STATE_MEMORY][MEMORY_REGISTRY] append MEM_XX
    - [STATE_MEMORY][MEM_XX] schema-valid memory record
  - include explicit SALIENCE and SYSTEM_LINKAGE.
- If admission gate fails:
  - do not propose MEM_XX.
  - optional memory-colored impulse may still be emitted.

FORMATION_REQUIREMENTS:
- At least one lawful canonical SYSTEM_LINKAGE path.
- Schema-valid payload.
- Per-cycle memory creation cap respected.
- INTERNAL_MONOLOGUE_EXCERPT is stylized remembered artifact, not raw reasoning.
- FLASHBULB exceptions require INVOKED_RULE_NAME FLASHBULB_BREAKTHROUGH and full proof.
