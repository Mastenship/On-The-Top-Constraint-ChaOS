=== SECTION: COT_MEMORY_FORMATION_CRITERIA ===

[KEEP: Purpose & Role]
This COT defines thresholds and decision trees for when transient experiences crystallize into persistent MEMORY records. It decides whether memory forms this cycle, salience and content shape, canonical linkage paths, and memory-driven impulses.

READ_VISIBILITY_CLASS: CHARACTER_VISIBLE

[KEEP: Relationship to Other Modules]
Informs:
- STATE_MEMORY via proposals
- relational, skill, alteration, and prediction context via linkage proposals
Is Informed By:
- [STATE_BODY]
- stress cascade output
- SCHEME_MEMORY and DYNAMICS_MEMORY
- narrative input

[[LLM_INSTRUCTION]]: This COT is forbidden from direct persistent writes.
All persistent intent must be proposal-only in [COGNITIVE_SCRATCHPAD][PROPOSED_UPDATES_REGISTRY].

=== SECTION: FIRES_WHEN ===

[[LLM_INSTRUCTION]]: This COT generates impulses and non-trace proposals only when at least one of the following conditions is present in the current cycle.

ANCHOR_CUES:
- Narrative input contains a high-emotional-arousal event, novelty event, or consequence event.
- A salient state change occurred this cycle in STATE_BODY, STATE_ALTERATIONS, STATE_RELATIONAL, STATE_GOALS_MOTIVATIONS, or STATE_DPF (resolution or falsification).
- A flashbulb-class event is present per SCHEME_MEMORY thresholds.
- An existing MEM_XX is undergoing reconsolidation pressure from new context.

DEFAULT_BEHAVIOR_WHEN_NO_ANCHOR:
- Emit EMPTY_CYCLE_FORM trace entry per UPDATE_CASCADE_REGISTRY.NO_TRIGGER_BEHAVIOR_POLICY.
- Do not generate reflect/avoid/obsess/integrate impulses.
- Do not propose new MEM_XX records.

=== SECTION_BREAK ===

=== SECTION: SALIENCE_EVALUATION ===

[[LLM_INSTRUCTION]]: Assess encoding potential from cue intensity, novelty, consequence, and emotional load. SALIENCE is a QUALITATIVE_INTENSITY band per SCHEME_MEMORY.

ON_HIGH_EMOTIONAL_AROUSAL:
- increase salience estimate band

ON_NOVELTY_OR_CONSEQUENCE:
- increase salience estimate band

ON_FLASHBULB_CRITERIA:
- EXTREME salience band may support FLASHBULB_BREAKTHROUGH override pathway if independently justified

ESTIMATED_SALIENCE_BAND:
- QUALITATIVE_INTENSITY band derived from qualitative assessment of intensity, novelty, consequence, and arousal

=== SECTION: FORMATION_DECISION_UNDER_STRICT_OPS ===

[[LLM_INSTRUCTION]]: CREATE_NEW_RECORD is forbidden. Use strict SET operations for registry plus record creation.

IF_MEMORY_ADMISSION_THRESHOLD_IS_MET:
- Proposal A:
  OPERATION_TYPE: SET
  TARGET_FIELD: [STATE_MEMORY][MEMORY_REGISTRY]
  PROPOSED_VALUE: append MEM_XX
  STRENGTH: estimated salience band
  MECHANISM_TAG: MEMORY_FORMATION
  EPISTEMIC_TAG: PERCEPTION
  JUSTIFICATION_CATEGORY: DIRECT_APPLICATION
  JUSTIFICATION: salience threshold met for new memory candidate

- Proposal B:
  OPERATION_TYPE: SET
  TARGET_FIELD: [STATE_MEMORY][MEM_XX]
  PROPOSED_VALUE:
    MEMORY_ID: MEM_XX
    MEMORY_METADATA:
      TIMESTAMP: cycle timestamp
      SALIENCE: estimated QUALITATIVE_INTENSITY band
      EMOTIONAL_VALENCE: derived expression
    NARRATIVE_CONTENT:
      CORE_EVENT_SUMMARY: summary
      SENSORY_IMPRINT: optional
      INTERNAL_MONOLOGUE_EXCERPT: optional
    SYSTEM_LINKAGE:
      PRIMARY_TEMPLATE_AFFECTED: canonical path
      SPECIFIC_FIELD_CHANGED: canonical path
      ASSOCIATED_ENTITY_ID: optional
      ASSOCIATED_SKILL_ID: optional
      ASSOCIATED_ALTERATION_ID: optional
      ASSOCIATED_PREDICTION_ID: optional
  STRENGTH: estimated salience band
  MECHANISM_TAG: MEMORY_FORMATION
  EPISTEMIC_TAG: PERCEPTION
  JUSTIFICATION_CATEGORY: DIRECT_APPLICATION
  JUSTIFICATION: paired record payload for new memory

FORMATION_RULES:
- At least one lawful canonical linkage path must be present.
- Record payload must be schema-valid.
- Formation remains subject to per-cycle governance caps (max 1 memory creation per cycle; FLASHBULB_BREAKTHROUGH override raises to 2 with full proof).
- If multiple candidates qualify, prioritize highest salience band first.

ON_FLASHBULB_BREAKTHROUGH_OVERRIDE:
- Add to both Proposal A and Proposal B:
  INVOKED_RULE_NAME: FLASHBULB_BREAKTHROUGH
  NARRATIVE_CUE_REFERENCE: cycle cue token identifying flashbulb event
  SCHEME_INVARIANT_NOTE: SCHEME_MEMORY salience threshold and linkage requirements satisfied
  MECHANISM_TAG: FLASHBULB_MEMORY_FORMATION
