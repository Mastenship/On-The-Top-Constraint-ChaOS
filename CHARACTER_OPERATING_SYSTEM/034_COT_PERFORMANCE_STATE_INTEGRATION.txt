=== SECTION: COT_PERFORMANCE_STATE_INTEGRATION ===

[KEEP: Purpose & Role]
This COT defines how arousal, stress, biochemical condition, and environment modulate skill execution in the moment. It produces temporary overlays targeting skill execution pathways, performance-related impulses, and rare permanent skill transitions only with override proof.

READ_VISIBILITY_CLASS: CHARACTER_VISIBLE

[KEEP: Relationship to Other Modules]
Informs:
- temporary performance overlays
- DECISION synthesis impulses
- memory cues
Is Informed By:
- [STATE_BODY]
- stress cascade input
- SCHEME_SKILLS and DYNAMICS_SKILLS
- narrative context

=== SECTION: FIRES_WHEN ===

[[LLM_INSTRUCTION]]: This COT generates impulses and non-trace proposals only when at least one of the following conditions is present in the current cycle.

ANCHOR_CUES:
- Narrative input describes the character executing or attempting a SKL_XX skill.
- Current STATE_BODY shows arousal outside the optimal band (ADRENALINE not BASELINE, or CORTISOL above ELEVATED).
- Environmental pressure cue affects skill execution context.
- A breakthrough or failure event with explicit MEM_XX linkage candidate is present.

DEFAULT_BEHAVIOR_WHEN_NO_ANCHOR:
- Emit EMPTY_CYCLE_FORM trace entry per UPDATE_CASCADE_REGISTRY.NO_TRIGGER_BEHAVIOR_POLICY.
- Do not generate push_through/seek_optimal/conserve/quit impulses.
- Do not propose performance-modifier overlays.

  STRENGTH: HIGH
  MECHANISM_TAG: SKILL_STATE_CHANGE
  EPISTEMIC_TAG: COMMITTED_FACT
  EVIDENCE_REF: MEM_XX (linked breakthrough memory)
  INVOKED_RULE_NAME: SKILL_STATE_CHANGE
  NARRATIVE_CUE_REFERENCE: cycle cue token plus linked MEM_XX reference
  SCHEME_INVARIANT_NOTE: SCHEME_SKILLS one-step law and INSTINCT_LEVEL <= MASTERY_LEVEL preserved
  JUSTIFICATION_CATEGORY: INFERENTIAL_LEAP
  JUSTIFICATION: memory-linked consolidation cue with override proof

CONDITIONS:
- memory linkage must be explicit
- salience and repetition support must be present where relevant
- INSTINCT_LEVEL must not exceed MASTERY_LEVEL
- governance may downgrade or suppress if proof is insufficient
