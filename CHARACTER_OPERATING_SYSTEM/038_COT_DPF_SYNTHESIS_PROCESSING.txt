=== SECTION: DPF_SYNTHESIS ===

CORE_ASSUMPTION_SYNTHESIS:
- Integrate cues, active predictions, contradictions, drive urgency, goal pressure, belief priors, and background priors into CURRENT_DPF.
- If durable contrast event exists, propose bounded persistent DPF SET updates.
- If interpretation is transient, unresolved, or low-impact, keep it in CURRENT_DPF.

EMOTIONAL_VALENCE_AND_PACE:
- Derive from arousal, threat interpretation, certainty pressure, goal urgency, time pressure, and active modifiers.
- Persistent enum placement uses SET only when justified.

PERSISTENCE_RULE:
- STATE_DPF stores resolved interpretive state, not raw intermediate reasoning.
- Do not duplicate belief, memory, or goal records.

=== SECTION: PREDICTION_HANDLING ===

[[LLM_INSTRUCTION]]: Apply DYNAMICS_DPF.PREDICTION_WORTHINESS_GATE.

ON_PREDICTION_CANDIDATE:
- If gate passes:
  - PROPOSE SET pair:
    - [STATE_DPF][PREDICTION_REGISTRY] append PRD_XX
    - [STATE_DPF][PRD_XX] schema-valid prediction record
  - respect MAX_ACTIVE_PREDICTIONS.
- If gate fails:
  - keep interpretation in CURRENT_DPF or temporary modifier.

ON_CERTAINTY_ADJUSTMENT:
- PROPOSE SET to adjacent QUALITATIVE_INTENSITY band on PRD_XX.CERTAINTY or DPF CERTAINTY_LEVEL.VALUE.

ON_RESOLUTION_OR_FALSIFICATION:
- PROPOSE SET PRD_XX.STATE to RESOLVED, RESOLVED_NEGATIVE, or FALSIFIED.
- COMMITTED_FACT lifecycle closure requires lawful EVIDENCE_REF.
