=== SECTION: COT_DPF_SYNTHESIS_PROCESSING ===

[KEEP: Purpose & Role]
This COT synthesizes the character DOMINANT_PREDICTIVE_FRAME (DPF) as integrated cycle state. It does not narrate and does not select actions. It produces a current-cycle DPF snapshot in [COGNITIVE_SCRATCHPAD][CURRENT_DPF] and proposals for persistent DPF updates via strict operation set.

READ_VISIBILITY_CLASS: CHARACTER_VISIBLE

[KEEP: Relationship to Other Modules]
Informs:
- DECISION synthesis via current DPF snapshot
- STATE_DPF updates through proposals
Is Informed By:
- narrative cues
- active predictions
- SCHEME_DPF and DYNAMICS_DPF
- SCHEME_BACKGROUND

=== SECTION_BREAK ===

=== SECTION: WRITE_POLICY_OVERRIDE ===

[[LLM_INSTRUCTION]]: This COT may not directly edit persistent modules.

Allowed writes:
- [COGNITIVE_SCRATCHPAD][CURRENT_DPF]
- [COGNITIVE_SCRATCHPAD][PROPOSED_UPDATES_REGISTRY]
- [COGNITIVE_SCRATCHPAD][CASCADE_TRACE]

All proposals must use strict OPERATION_TYPE set.

=== SECTION: DPF_SYNTHESIS ===

[[LLM_INSTRUCTION]]: Build current snapshot and propose bounded persistent updates only where persistent change is warranted.

CORE_ASSUMPTION_SYNTHESIS:
- Integrate cues, active predictions, contradictions, and drive urgency into a current-cycle interpretive summary.
- If a durable contrast event is detected, propose explicit SET updates to relevant persistent DPF fields.

EMOTIONAL_VALENCE_AND_PACE:
- Derive from arousal, threat interpretation, certainty pressure, and time pressure.
- Use SET for persistent enum placements when justified.
- Keep volatile intermediate interpretation in [COGNITIVE_SCRATCHPAD][CURRENT_DPF].

PREDICTION_HANDLING:
[[LLM_INSTRUCTION]]: CERTAINTY on prediction records is a QUALITATIVE_INTENSITY band. Use SET to adjacent bands. New prediction creation uses SET pair pattern. Active prediction count is governance-capped at MAX_ACTIVE_PREDICTIONS = 10.

NEW_PREDICTION_INSERTION:
- Proposal A:
  OPERATION_TYPE: SET
  TARGET_FIELD: [STATE_DPF][PREDICTION_REGISTRY]
  PROPOSED_VALUE: append PRD_XX
  STRENGTH: MODERATE
  MECHANISM_TAG: PREDICTION_FORMATION
  EPISTEMIC_TAG: INFERENCE
  JUSTIFICATION_CATEGORY: INFERENTIAL_LEAP
  JUSTIFICATION: anticipatory framing warranted by cue pattern
- Proposal B:
  OPERATION_TYPE: SET
  TARGET_FIELD: [STATE_DPF][PRD_XX]
  PROPOSED_VALUE: schema-valid prediction record per SCHEME_DPF.PREDICTION_RECORD_SCHEMA
  STRENGTH: MODERATE
  MECHANISM_TAG: PREDICTION_FORMATION
  EPISTEMIC_TAG: INFERENCE
  JUSTIFICATION_CATEGORY: INFERENTIAL_LEAP
  JUSTIFICATION: paired record payload for new prediction

CERTAINTY_ADJUSTMENT:
- PROPOSE SET:
  TARGET_FIELD: [STATE_DPF][PRD_XX][CERTAINTY]
  PROPOSED_VALUE: adjacent QUALITATIVE_INTENSITY band
  STRENGTH: LOW
  MECHANISM_TAG: PREDICTION_CERTAINTY_ADJUSTMENT
  EPISTEMIC_TAG: INFERENCE
  JUSTIFICATION_CATEGORY: INFERENTIAL_LEAP
  JUSTIFICATION: cue evidence shifts prediction certainty

RESOLUTION_OR_FALSIFICATION:
- PROPOSE SET:
  TARGET_FIELD: [STATE_DPF][PRD_XX][STATE]
  PROPOSED_VALUE: RESOLVED | RESOLVED_NEGATIVE | FALSIFIED
  STRENGTH: HIGH
  MECHANISM_TAG: PREDICTION_LIFECYCLE_CLOSURE
  EPISTEMIC_TAG: COMMITTED_FACT
  EVIDENCE_REF: cycle cue or MEM_XX reference establishing outcome
  JUSTIFICATION_CATEGORY: DIRECT_APPLICATION
  JUSTIFICATION: prediction outcome cue resolves lifecycle

PREDICTION_CAP_HANDLING:
- If proposing new prediction would exceed MAX_ACTIVE_PREDICTIONS:
  - either include concurrent SET to resolve or falsify the lowest-certainty existing prediction
  - or accept governance suppression with DPF_PREDICTION_CAP_EXCEEDED

PERSISTENCE_RULE:
- Persistent STATE_DPF should store resolved interpretive state, not raw intermediate reasoning.
- If synthesis produces only transient tension, retain it in CURRENT_DPF or modifiers rather than forcing baseline mutation.

=== SECTION: BACKGROUND_GROUNDING ===

[[LLM_INSTRUCTION]]: SCHEME_BACKGROUND outlook fields supply normative interpretive priors for DPF synthesis. Consult these as biases on CORE_ASSUMPTION, EMOTIONAL_VALENCE, SOURCE_CAUSALITY, and SOCIAL_STANCE inference. SCHEME_BACKGROUND is never mutated by this COT; it is read-only interpretive context.

CONSULTED_FIELDS:
- [SCHEME_BACKGROUND][OUTLOOK_ON_AUTHORITY]
- [SCHEME_BACKGROUND][OUTLOOK_ON_OUTSIDERS_AND_STRANGERS]
- [SCHEME_BACKGROUND][OUTLOOK_ON_FATE_VS_FREE_WILL]
- [SCHEME_BACKGROUND][OUTLOOK_ON_LAW_AND_ORDER]
- [SCHEME_BACKGROUND][OUTLOOK_ON_THE_FUTURE]

APPLICATION_RULES:
- OUTLOOK_ON_AUTHORITY biases SOCIAL_STANCE toward TRUSTING (RESPECTFUL/SUBMISSIVE), NEUTRAL (QUESTIONING), or SUSPICIOUS/HOSTILE (CYNICAL) interpretations of authority-bearing entities.
- OUTLOOK_ON_OUTSIDERS_AND_STRANGERS biases SOCIAL_STANCE toward stranger-class entities along the same gradient.
- OUTLOOK_ON_FATE_VS_FREE_WILL biases SOURCE_CAUSALITY between SCIENTIFIC/HUMAN_AGENCY (SELF_DETERMINIST) and SUPERNATURAL/RANDOM (FATALISTIC/THEOLOGICALLY_DETERMINED).
- OUTLOOK_ON_LAW_AND_ORDER biases interpretive framing of normative-violation cues.
- OUTLOOK_ON_THE_FUTURE biases EMOTIONAL_VALENCE baseline toward HOPEFUL (OPTIMISTIC), CAUTIOUS/ANXIOUS (PESSIMISTIC), DREAD (APOCALYPTIC), or NUMB (CYCLICAL).

CONSULTATION_BOUNDS:
- Background priors bias inference; they do not override cue evidence.
- Background priors are not stacked additively with trait modulation; they act as interpretive context only.
- No proposal targets SCHEME_BACKGROUND under any circumstance.
