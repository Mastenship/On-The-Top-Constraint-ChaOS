=== SECTION: STRESS_AND_AROUSAL_EFFECTS ===

ON_HIGH_AROUSAL_OR_STRESS:
- Prefer ADD_MODIFIER overlays for:
  - SPEECH_RATE_PRESSURE
  - COMMUNICATION_COMPLEXITY_COMPRESSION
  - EMOTIONAL_LEAKAGE
- Baseline communication fields do not shift unless persistence evidence supports enduring adaptation.

ON_FATIGUE:
- Prefer ADD_MODIFIER overlays for FATIGUE_DELIVERY_DEGRADATION.
- Durable baseline change requires persistence cluster evidence.

ON_DECEPTION_OR_CONCEALMENT:
- Prefer ADD_MODIFIER overlays for masking load, tell suppression, leakage risk, or guardedness.
- Deception episode effects do not rewrite stable communication identity without persistence cluster evidence.

=== SECTION: PERSISTENCE_TRIGGER_RULE ===

[[LLM_INSTRUCTION]]: Persistence for communication baseline shift is operationalized through the memory ledger.

PERSISTENCE_CLUSTER_EXISTS_FOR_FIELD_F_WHEN:
- Three or more MEM_XX records reference field F through SYSTEM_LINKAGE.SPECIFIC_FIELD_CHANGED or CORE_EVENT_SUMMARY.
- Records carry consistent direction toward the same lawful adjacent enum value.
- At least one record has SALIENCE MODERATE or higher.
- Records are distinct cue occasions, not duplicate encodings.

PERSISTENCE_TRIGGERED_BASELINE_SHIFT:
- When cluster exists and current cycle adds consistent cue evidence:
  - PROPOSE SET:
    TARGET_FIELD: [STATE_COMMUNICATION_DIALOGUE][<canonical communication field path>]
    PROPOSED_VALUE: next lawful adjacent enum value in consistent direction
    INVOKED_RULE_NAME: PERSISTENT_EVIDENCE_ACCUMULATION
    NARRATIVE_CUE_REFERENCE: cycle cue token plus contributing MEM_XX references
    EVIDENCE_REF: [MEM_XX, MEM_XX, MEM_XX]
    SCHEME_INVARIANT_NOTE: communication baseline shift accommodated under accumulated evidence; one adjacent enum step
    MECHANISM_TAG: COMMUNICATION_PERSISTENCE_ACCOMMODATION

PERSISTENCE_BOUNDS:
- One adjacent enum step per field per cycle.
- A persistence cluster is conceptually consumed; later shifts require new cue accumulation.
- Stress-only or fatigue-only clusters must show enduring adaptation, not repeated transient impairment.

=== SECTION: CULTURAL_AND_RELATIONAL_ADAPTATION ===

ON_CULTURAL_EXPOSURE_WITH_OPENNESS:
- Persistent cultural adaptation uses PERSISTENCE_TRIGGER_RULE.
- Acute exposure uses transient overlays.

ON_RELATIONAL_SHIFT:
- Persistent changes to DIRECTNESS_LEVEL, POLITENESS_STRATEGY, PROXEMICS_PREFERENCE, or related fields use PERSISTENCE_TRIGGER_RULE.
- Acute relational pressure uses transient overlays.

ON_TRAUMA_OR_ANXIETY_CUES:
- Prefer ADD_MODIFIER overlays for speech blocks, guardedness, masking load, or reduced expressiveness before baseline changes.
