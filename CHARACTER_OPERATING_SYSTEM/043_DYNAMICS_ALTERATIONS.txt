=== SECTION: DYNAMICS_ALTERATIONS ===

[KEEP: Purpose & Role]
Immutable mechanics for alteration activation/deactivation, removal, rejection states, and cascade triggering.

=== SECTION_BREAK ===

=== SECTION: OPERATION_POLICY ===

[[LLM_INSTRUCTION]]: Dynamics must reference strict operation vocabulary only.
Allowed operation references:
- SET
- TRANSITION
- ADD_MODIFIER
- REMOVE_MODIFIER
- CAP
- VETO

Forbidden operation references:
- CREATE_NEW_RECORD
- UPDATE
- INCREMENT
- DECREMENT

=== SECTION_BREAK ===

=== SECTION: ACTIVATION_DEACTIVATION ===

ON_CONSTRAINT_MET:
- If STATUS = DORMANT and conditions are satisfied:
  Propose TRANSITION:
    TARGET_FIELD: [STATE_ALTERATIONS][ALT_XX][STATUS]
    PROPOSED_VALUE: ACTIVE
    JUSTIFICATION: activation condition satisfied

ON_CONSTRAINT_UNMET:
- If STATUS = ACTIVE:
  Propose TRANSITION:
    TARGET_FIELD: [STATE_ALTERATIONS][ALT_XX][STATUS]
    PROPOSED_VALUE: DORMANT
    JUSTIFICATION: activation condition no longer met

ON_REMOVAL_EVENT:
- Propose SET:
  TARGET_FIELD: [STATE_ALTERATIONS][ALT_XX][STATUS]
  PROPOSED_VALUE: INACTIVE or REMOVED
  JUSTIFICATION: removal cue

=== SECTION_BREAK ===

=== SECTION: PSYCHOLOGICAL_REJECTION ===

ON_TRAUMATIC_REJECTION:
- If linked memory salience threshold is met:
  Propose TRANSITION:
    TARGET_FIELD: [STATE_ALTERATIONS][ALT_XX][STATUS]
    PROPOSED_VALUE: REJECTED
    JUSTIFICATION: trauma-linked rejection cue

- Optionally trigger chronic stress overlay proposals via downstream COTs.

=== SECTION_BREAK ===

=== SECTION: CASCADE_TRIGGER ===

ON_STATUS_CHANGE:
- Trigger COT_ALTERATION_CASCADE_EFFECTS for propagation proposals.
- Dynamics does not directly write propagated effects.

=== SECTION: CASCADE_EFFECT_CLASS_INFERENCE ===

[[LLM_INSTRUCTION]]: Before generating cascade proposals, COT_ALTERATION_CASCADE_EFFECTS classifies each active or status-changed alteration into one or more of the following semantic effect classes. Classification is derived at runtime from the alteration record fields; no separate stored classification field is required.

INJURY_OR_ILLNESS_CLASS:
- Infer this class when PHYSIOLOGICAL_CHANGES describes damage, disease, infection, organ impairment, wound, or compromised biological function.
- Also infer when OBJECTIVE_SYSTEM_EFFECTS names a debilitating physiological condition as a direct outcome.
- Drives: physiological state proposals targeting STATE_BODY fields (IMMUNE_MARKERS, WOUND_STATUS, or equivalent).
- Focus: what the alteration does to the body's physical integrity or health state.
- Distinction from DEBILITATING_CLASS: INJURY_OR_ILLNESS_CLASS addresses biological state and drives STATE_BODY proposals; DEBILITATING_CLASS addresses functional capability loss and drives STATE_TEMPORARY_MODIFIERS proposals. An alteration that causes both tissue damage and capability loss qualifies for both classes independently; MULTI_CLASS_RESOLUTION applies.

ENHANCEMENT_CLASS:
- Infer this class when NEW_ABILITIES lists capabilities that exceed the character's prior unaided baseline.
- Also infer when OBJECTIVE_SYSTEM_EFFECTS names performance augmentation, expanded sensory range, or added function.
- Drives: temporary performance overlay proposals targeting STATE_TEMPORARY_MODIFIERS with EFFECT_FAMILY in the ALTERATION_SKILL_ENHANCEMENT family.

DEBILITATING_CLASS:
- Infer this class when VULNERABILITIES_CONSTRAINTS describes functional reduction, capacity loss, action restriction, or performance penalty.
- Also infer when OBJECTIVE_SYSTEM_EFFECTS names a debilitating functional consequence separate from tissue integrity loss.
- Drives: temporary degradation overlay proposals targeting STATE_TEMPORARY_MODIFIERS with EFFECT_FAMILY in the ALTERATION_SKILL_DEGRADATION family.
- Focus: what the alteration prevents or degrades in terms of the character's functional capabilities and available actions.
- Distinction from INJURY_OR_ILLNESS_CLASS: DEBILITATING_CLASS addresses capability state and drives STATE_TEMPORARY_MODIFIERS proposals; INJURY_OR_ILLNESS_CLASS addresses biological state and drives STATE_BODY proposals. An alteration involving tissue damage that also restricts function qualifies for both classes independently; MULTI_CLASS_RESOLUTION applies.

REJECTED_PSYCHOLOGICAL_CLASS:
- Infer this class when STATUS = REJECTED and CHARACTER_AWARENESS.AWARENESS_STATUS is not UNAWARE.
- Drives: chronic stress overlay proposals targeting STATE_TEMPORARY_MODIFIERS with EFFECT_FAMILY ALTERATION_REJECTION_STRESS, regardless of other class assignments.

MULTI_CLASS_RESOLUTION:
- An alteration may satisfy multiple cascade effect classes simultaneously.
- Each applicable class is evaluated independently; all warranted cascade proposals are generated within per-cycle governance caps defined in STATE_GOVERNANCE_OVERLAY.NON_NEGOTIABLE_WRITE_CONTRACT.STEP_LIMITS_PER_CYCLE.
- No class takes precedence over another; when governance caps are reached, proposals are suppressed or resolved per the conflict-resolution precedence defined in STATE_GOVERNANCE_OVERLAY.CONFLICT_RESOLUTION_POLICY.

CLASSIFICATION_SCOPE:
- Classification is a runtime inference performed by the executing COT and recorded in its TRACE_ENTRY NOTES field.
- Classification is not stored as a persistent field on the alteration record.
- The verifier confirms class inference consistency against the alteration record when a CASCADE_TRACE entry is present for COT_ALTERATION_CASCADE_EFFECTS.
