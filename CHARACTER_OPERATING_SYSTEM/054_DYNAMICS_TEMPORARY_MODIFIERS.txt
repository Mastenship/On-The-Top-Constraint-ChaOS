=== SECTION: ACTIVE_SURFACE_MODEL ===

ACTIVE_SURFACE_RULES:
- Temporary modifiers are active transient overlays, not historical records.
- Expired or removed modifiers leave the active surface.
- Lifecycle closure belongs in governance audit and trace.
- Active modifiers modulate targets; they do not mutate target baselines.

=== SECTION: MATCH_KEY_TUPLE ===

[[LLM_INSTRUCTION]]: Material sameness requires exact match on all tuple components.

MATCH_KEY_TUPLE_COMPONENTS:
- MODIFIER_TYPE
- MECHANISM_TAG
- TARGET_FIELD
- TARGET_ID (NONE compares as NONE)
- EFFECT_FAMILY

EFFECT_FAMILY_RULE:
- EFFECT_FAMILY is the canonical semantic effect token supplied by the proposing COT.
- Same EFFECT_FAMILY with different EFFECT_EXPRESSION is materially same only when all tuple components match.
- Same EFFECT_EXPRESSION with different EFFECT_FAMILY is materially different.

MATERIAL_SAMENESS_OUTCOME:
- All components match: refresh-or-replace pathway.
- Any component differs: coexistence pathway.

=== SECTION: REFRESH_AND_COLLISION ===

DETERMINISTIC_RESOLUTION_ORDER:
1) Search active modifiers for MATCH_KEY_TUPLE collision.
2) If no collision: create new MOD_XX only when coexistence is lawful.
3) If materially same and STACKING_RULE = REPLACE: replace existing in place using same MOD_XX.
4) If materially same and STACKING_RULE is not REPLACE: refresh existing in place using same MOD_XX.
5) If materially different on same target: create new only if coexistence is lawful and bounded; otherwise suppress.

IN_PLACE_RULE:
- REFRESH_EXISTING and REPLACE_EXISTING do not create a new MOD_XX.
- Registry remains unchanged.
- LAST_REFRESHED updates.
- CREATED_TIMESTAMP is preserved.

=== SECTION_BREAK ===

=== SECTION: STACKING_AND_CAP_BEHAVIOR ===

STACKING_RULE_INTERPRETATION:
- STACK: bounded concurrent overlays when materially different.
- REPLACE: newer materially same payload supersedes existing in place.
- CAP: aggregate effect cannot exceed qualitative ceiling.
- MULTIPLY: rare; requires explicit bounded justification.

COEXISTENCE_RULE:
- Concurrent modifiers require material difference, target compatibility, and governance cap compliance.
- Same-family pressure on same target normally refreshes or replaces.
- Multiple modifiers must not simulate permanent baseline change without lawful persistent proposal.

CAP_BEHAVIOR:
- CAP limits aggregate modifier effect.
- CAP does not mutate target baseline.
- CAP outcomes must be audit- or trace-visible.

=== SECTION_BREAK ===

=== SECTION: EXPIRY_TRANSITIONS ===

ON_EXPIRY_CONDITION_MET:
- Propose REMOVE_MODIFIER.
- Justification: expiry condition satisfied.

ON_SCENE_CLOSURE:
- Remove SCENE-duration modifiers unless refreshed.

ON_UNTIL_CONDITION_RESOLUTION:
- Remove UNTIL_CONDITION modifiers when named condition no longer applies.

ON_FIXED_CYCLE_LAPSE:
- Remove FIXED_CYCLES modifiers when cycle bound is exhausted.

ON_PERSISTENT_UNTIL_REFRESH_STALE:
- Refresh only if originating condition remains active.
- Otherwise propose REMOVE_MODIFIER.

EXPIRY_RESULT:
- Active influence ends.
- Persistent retention inside STATE_TEMPORARY_MODIFIERS is not required.

=== SECTION_BREAK ===

=== SECTION: REMOVE_MODIFIER_BEHAVIOR ===

ON_REMOVE_MODIFIER_PROPOSAL:
- Remove targeted modifier record.
- Remove corresponding MOD_XX from MODIFIER_REGISTRY.
- Preserve lifecycle closure in governance audit and trace.
