=== SECTION: COT_GOAL_PURSUIT_OPTIMIZATION ===

[KEEP: Purpose & Role]
Processes active goals and drive states into goal-directed impulses and optional goal-pressure overlays. Creates GOAL_XX records only through DYNAMICS_GOALS_MOTIVATIONS.GOAL_WORTHINESS_GATE.

READ_VISIBILITY_CLASS: CHARACTER_VISIBLE

[KEEP: Relationship to Other Modules]
Informs: DECISION impulses, memory cues, stress/frustration pressure, DPF prediction support.
Is Informed By: STATE_GOALS_MOTIVATIONS, STATE_BODY, STATE_DPF, STATE_TEMPORARY_MODIFIERS, SCHEME_GOALS_MOTIVATIONS, DYNAMICS_GOALS_MOTIVATIONS, DYNAMICS_DPF, narrative input.

=== SECTION: FIRES_WHEN ===

ANCHOR_CUES:
- GOAL_XX exists with STATUS = ACTIVE or BLOCKED.
- A drive state is MODERATE or higher.
- Narrative input introduces opportunity, obstacle, progress cue, deadline, resource change, or cost cue relevant to an active goal.
- Two or more active goals conflict.
- Narrative input introduces pressure that may satisfy DYNAMICS_GOALS_MOTIVATIONS.GOAL_WORTHINESS_GATE.

DEFAULT_BEHAVIOR_WHEN_NO_ANCHOR:
- EMPTY_CYCLE_FORM only, per UPDATE_CASCADE_REGISTRY.NO_TRIGGER_BEHAVIOR_POLICY.

=== SECTION_BREAK ===

=== SECTION: DRIVE_AND_GOAL_PRIORITIZATION ===

ON_HIGH_URGENCY_DRIVE:
- Prioritize physiological and safety-constrained goals.
- Propose bounded SET or TRANSITION updates to urgency-linked fields when justified.
- If no existing GOAL_XX captures pressure, apply DYNAMICS_GOALS_MOTIVATIONS.GOAL_WORTHINESS_GATE.

ON_OPPORTUNITY_OR_PROGRESS:
- Prefer updates to existing GOAL_XX over new goal creation.
- Propose bounded confidence, urgency, progress, or status shifts when cue support exists.

ON_OBSTACLE_OR_BLOCKAGE:
- Propose bounded CONFIDENCE, STATUS, URGENCY, or OBSTACLES_ANTICIPATED updates when cue support exists.
- Use temporary overlays for short-horizon frustration or pressure.

ON_GOAL_CONFLICT:
- Classify conflict per DYNAMICS_GOALS_MOTIVATIONS.CONFLICT_TYPES.
- Prefer short-horizon GOAL_CONFLICT_PRESSURE modifier when durable goal rewrite is not warranted.

GOAL_CONFLICT_PRESSURE_PATTERN:
- PROPOSE ADD_MODIFIER:
  TARGET_FIELD: [STATE_TEMPORARY_MODIFIERS][MOD_XX]
  PROPOSED_VALUE:
    MODIFIER_TYPE: PSYCHOLOGICAL_MODIFIER
    EFFECT_FAMILY: GOAL_CONFLICT_PRESSURE
    EFFECT_EXPRESSION: tension between competing active goals
    MAGNITUDE: MODERATE
    STACKING_RULE: REPLACE
    DURATION_TYPE: UNTIL_CONDITION
    EXPIRY_CONDITION: conflict resolved or one goal abandoned
  STRENGTH: MODERATE
  MECHANISM_TAG: GOAL_CONFLICT_RESOLUTION_PRESSURE
  EPISTEMIC_TAG: INFERENCE
  JUSTIFICATION_CATEGORY: GOAL_DIRECTED
  JUSTIFICATION: competing goal pressure cue

=== SECTION: GOAL_RECORD_MUTATION ===

ON_NEW_GOAL_PRESSURE:
- Apply DYNAMICS_GOALS_MOTIVATIONS.GOAL_WORTHINESS_GATE.
- If admitted:
  - PROPOSE SET pair:
    - [STATE_GOALS_MOTIVATIONS][GOAL_REGISTRY] append GOAL_XX
    - [STATE_GOALS_MOTIVATIONS][GOAL_XX] schema-valid goal record
  - MECHANISM_TAG: GOAL_FORMATION
  - JUSTIFICATION_CATEGORY: GOAL_DIRECTED
- If not admitted:
  - express pressure as impulse, selected action, temporary modifier, or CURRENT_DPF interpretation.

ON_EXISTING_GOAL_UPDATE:
- Use SET or TRANSITION on canonical goal fields.
- Qualitative endpoint movement remains one-band bounded unless override proof is complete.
- STATUS changes require explicit cue or event support.
