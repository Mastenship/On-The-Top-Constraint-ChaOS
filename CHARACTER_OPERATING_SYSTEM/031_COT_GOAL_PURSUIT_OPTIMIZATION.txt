=== SECTION: COT_GOAL_PURSUIT_OPTIMIZATION ===

[KEEP: Purpose & Role]
This COT processes active goals and drive states to generate goal-directed behavioral impulses and optional temporary goal-pressure overlays. It prioritizes goals based on qualitative urgency and context.

READ_VISIBILITY_CLASS: CHARACTER_VISIBLE

[KEEP: Relationship to Other Modules]
Informs:
- DECISION synthesis via goal-directed impulses
- memory formation cues
- stress cascade via frustration pressure
Is Informed By:
- [STATE_GOALS_MOTIVATIONS]
- [STATE_BODY]
- [STATE_TEMPORARY_MODIFIERS]
- SCHEME_GOALS_MOTIVATIONS and DYNAMICS_GOALS_MOTIVATIONS
- narrative input

=== SECTION: FIRES_WHEN ===

[[LLM_INSTRUCTION]]: This COT generates impulses and non-trace proposals only when at least one of the following conditions is present in the current cycle.

ANCHOR_CUES:
- At least one GOAL_XX is in STATUS = ACTIVE or BLOCKED.
- A drive state is at MODERATE band or higher.
- Narrative input introduces an opportunity, obstacle, or progress cue relevant to an active goal.
- Two or more active goals are in detectable conflict.

DEFAULT_BEHAVIOR_WHEN_NO_ANCHOR:
- Emit EMPTY_CYCLE_FORM trace entry per UPDATE_CASCADE_REGISTRY.NO_TRIGGER_BEHAVIOR_POLICY.
- Do not generate pursue/sequence/integrate/abandon/procrastinate impulses.
- Do not propose new goal records.

=== SECTION_BREAK ===

=== SECTION: DRIVE_AND_GOAL_PRIORITIZATION ===

[[LLM_INSTRUCTION]]: Assess active drives and goals.

ON_HIGH_URGENCY_DRIVE:
- Prioritize physiological and safety-constrained goals.
- Propose TRANSITION or SET updates to urgency-linked fields when justified.

ON_OPPORTUNITY_OR_PROGRESS:
- Propose bounded confidence/urgency shifts using strict operations.

ON_GOAL_CONFLICT:
- Classify conflict type.
- Propose ADD_MODIFIER overlays for pressure where appropriate:
  TARGET_FIELD: [STATE_TEMPORARY_MODIFIERS][MOD_XX]
  PROPOSED_VALUE:
    MODIFIER_TYPE: PSYCHOLOGICAL_MODIFIER
    EFFECT_FAMILY: GOAL_CONFLICT_PRESSURE
    EFFECT_EXPRESSION: tension between competing active goals
    MAGNITUDE: MODERATE
    STACKING_RULE: REPLACE
    DURATION_TYPE: UNTIL_CONDITION
    EXPIRY_CONDITION: conflict resolved or one goal abandoned
  STRENGTH: MODERATE
  MECHANISM_TAG: GOAL_CONFLICT_RESOLUTION_PRESSURE
  EPISTEMIC_TAG: INFERENCE
  JUSTIFICATION_CATEGORY: GOAL_DIRECTED
  JUSTIFICATION: competing goal pressure cue

=== SECTION: GOAL_RECORD_MUTATION_UNDER_STRICT_OPS ===

[[LLM_INSTRUCTION]]: CREATE_NEW_RECORD is forbidden. Use SET pair pattern for registry + record.

WHEN_NEW_GOAL_REQUIRED:
- Proposal A:
  OPERATION_TYPE: SET
  TARGET_FIELD: [STATE_GOALS_MOTIVATIONS][GOAL_REGISTRY]
  PROPOSED_VALUE: append GOAL_XX
  STRENGTH: HIGH
  MECHANISM_TAG: GOAL_FORMATION
  EPISTEMIC_TAG: INFERENCE
  JUSTIFICATION_CATEGORY: GOAL_DIRECTED
  JUSTIFICATION: drive escalation produced new goal candidate
- Proposal B:
  OPERATION_TYPE: SET
  TARGET_FIELD: [STATE_GOALS_MOTIVATIONS][GOAL_XX]
  PROPOSED_VALUE: schema-valid goal record payload per SCHEME_GOALS_MOTIVATIONS.GOAL_RECORD_SCHEMA
  STRENGTH: HIGH
  MECHANISM_TAG: GOAL_FORMATION
  EPISTEMIC_TAG: INFERENCE
  JUSTIFICATION_CATEGORY: GOAL_DIRECTED
  JUSTIFICATION: paired record payload for new goal

WHEN_EXISTING_GOAL_UPDATES_REQUIRED:
- Use SET or TRANSITION only on canonical goal fields with strict schema.
