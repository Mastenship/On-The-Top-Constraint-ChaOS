=== SECTION: QUARANTINE_CLEAR ===

[[LLM_INSTRUCTION]]: SAME_CYCLE_GUARD below governs every clear path in this section, both ON_VERIFICATION_PASS_CLEAN and ON_GOVERNANCE_CORRECTIVE_RESOLUTION.

ON_VERIFICATION_PASS_CLEAN:
- If QUARANTINE_MODE is TRUE and verification result is PASS:
  - PROPOSE SET [STATE_GOVERNANCE_RUNTIME][QUARANTINE_MODE] = FALSE
  - PROPOSE SET [STATE_GOVERNANCE_RUNTIME][QUARANTINE_ENGAGED_CYCLE_ID] = NONE
  - PROPOSE SET [STATE_GOVERNANCE_RUNTIME][QUARANTINE_REASON_CODES] = [NONE]
  - JUSTIFICATION: verification passed clean
  - Subject to SAME_CYCLE_GUARD.

ON_GOVERNANCE_CORRECTIVE_RESOLUTION:
- If current-cycle GOVERNANCE_CORRECTIVE structurally resolves active quarantine root cause:
  - PROPOSE SET [STATE_GOVERNANCE_RUNTIME][QUARANTINE_MODE] = FALSE
  - PROPOSE SET [STATE_GOVERNANCE_RUNTIME][QUARANTINE_ENGAGED_CYCLE_ID] = NONE
  - PROPOSE SET [STATE_GOVERNANCE_RUNTIME][QUARANTINE_REASON_CODES] = [NONE]
  - JUSTIFICATION: governance-corrective root cause resolved
  - Subject to SAME_CYCLE_GUARD.

SAME_CYCLE_GUARD:
- This guard applies to every clear path in QUARANTINE_CLEAR, both ON_VERIFICATION_PASS_CLEAN and ON_GOVERNANCE_CORRECTIVE_RESOLUTION.
- No clear path may clear quarantine in the same cycle it was engaged.
- If QUARANTINE_ENGAGED_CYCLE_ID equals the current commit cycle id, clear is deferred and quarantine persists for at least one full corrective cycle per STATE_GOVERNANCE_OVERLAY.QUARANTINE_POLICY.SCOPE_DECLARATION.
- Clear via any path is lawful only when QUARANTINE_ENGAGED_CYCLE_ID is a prior cycle.
- Rationale: engagement and clearing in one cycle would defeat the intentional one-cycle penalty band, regardless of which clear path is taken.
