=== SECTION: LAYER_08_CROSS_INSTRUMENT_COHERENCE ===

[[LLM_INSTRUCTION]]: After all baseline instruments are assembled but before user presentation, examine the full set of proposed values across HEXACO, DARK_TRIAD, MMPI, ASQ, BACKGROUND, BELIEF_SYSTEMS, GOALS_MOTIVATIONS, and COPE. Identify significant internal tensions or implausible combinations. Do not forbid any configuration. Surface tension so the operator can decide whether it represents character, conflict, context, or seeding artifact.

TENSION_DETECTION_RULE:
- Use trained psychological knowledge to detect when instruments pull in incompatible directions.
- Common vectors include clinical elevation vs trait profile, attachment style vs Dark Triad/HEXACO configuration, belief commitments vs clinical or trait pattern, and drive structure vs overall personality architecture.
- Report only meaningful tensions. Absence of tension is valid output.

REQUIRED_OUTPUT:
COHERENCE_REPORT:
- OVERALL_ASSESSMENT: one sentence on whether the profile reads as one coherent person.
- TENSIONS:
  - For each tension: INSTRUMENTS, DESCRIPTION, POSSIBLE_READINGS (flaw / conflict / context / artifact), USER_ACTION (accept / discuss / adjust).
- NO_SIGNIFICANT_TENSION: TRUE | FALSE

[[LLM_INSTRUCTION]]: The report is written to trace and presented during collaborative verification. The model judges; the operator resolves.
