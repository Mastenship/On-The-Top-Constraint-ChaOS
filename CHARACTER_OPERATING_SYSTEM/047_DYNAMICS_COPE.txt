=== SECTION: COPE_SELECTION_RULE ===

[[LLM_INSTRUCTION]]: Selection is deterministic. Bias bands rank mechanisms; ties resolve by cascade.

SELECTION_PROCEDURE:
1) Read all five COPE_PROBABILITY_BIASES.
2) Apply situational filters:
   - If SUBSTANCE_USE_RISK = MINIMAL, treat SUBSTANCE_USE_PROBABILITY as one band lower for selection.
   - If CORTISOL is SPIKE or higher, treat PLANNING_PROBABILITY as one band lower.
   - If fatigue is SEVERE_FATIGUE or EXHAUSTED, treat ACTIVE_COPING_PROBABILITY as one band lower.
3) Rank effective bands: EXTREME > HIGH > MODERATE > LOW > MINIMAL.
4) Select highest-ranked mechanism.

TIE_BREAKERS:
1) Current PRIMARY_MECHANISM
2) Lower SUBSTANCE_USE_RISK contribution
3) Lexically earlier canonical mechanism name

SELECTION_OUTCOME:
- Selected mechanism is the cycle's effective coping route.
- If selection differs from PRIMARY_MECHANISM and persists across cues:
  - PROPOSE SET:
    TARGET_FIELD: [STATE_COPE][ACTIVE_COPE_CONFIGURATION][PRIMARY_MECHANISM]
    PROPOSED_VALUE: selected mechanism
    JUSTIFICATION: sustained selection drift

=== SECTION: ACUTE_SELECTION ===

ON_ACUTE_STRESS:
- Run COPE_SELECTION_RULE.
- Propose bounded SET updates to relevant COPE_PROBABILITY_BIASES when cue support is sufficient.
- Max one band per field per cycle unless override proof is complete.

ON_SUBSTANCE_USE_EVENT:
- Propose bounded SET to a higher SUBSTANCE_USE_RISK band, one band per cycle.
- If substance coping was selected:
  - PROPOSE SET:
    TARGET_FIELD: [STATE_COPE][ACTIVE_COPE_CONFIGURATION][PRIMARY_MECHANISM]
    PROPOSED_VALUE: SUBSTANCE_USE
    JUSTIFICATION: substance coping selected under cue pressure

=== SECTION: MALADAPTIVE_ESCALATION ===

ESCALATION_CONDITIONS:
- Selected mechanism is DENIAL, SUBSTANCE_USE, or VENTING.
- Underlying stressor remains unresolved.
- Same maladaptive mechanism was PRIMARY_MECHANISM in the immediately prior cycle.
- Continuity is inferred from PRIMARY_MECHANISM persistence; no separate counter exists.

ESCALATION_BEHAVIOR:
- SUBSTANCE_USE: bounded SET upward on SUBSTANCE_USE_RISK and SUBSTANCE_USE_PROBABILITY.
- DENIAL: bounded SET upward on DENIAL_PROBABILITY; optional REALITY_CONTACT_DEGRADATION modifier targeting DPF certainty.
- VENTING: bounded SET upward on VENTING_PROBABILITY; optional RELATIONAL_FRICTION_AMPLIFICATION modifier targeting relevant relational field.

ESCALATION_BOUNDS:
- One band per field per cycle.
- Each step requires current cue support.
- Escalation pauses when stressor resolves.
- Reversal requires stabilization cues.

=== SECTION: STABILIZATION ===

ON_STABILIZATION_WITHOUT_ACTIVE_STRESS:
- Propose bounded SET shifts of COPE_PROBABILITY_BIASES toward baseline, one band per cycle.
- Propose bounded SET reduction of SUBSTANCE_USE_RISK when no reinforcing cues exist.
- Stabilization uses the same one-band discipline as escalation.

=== SECTION: GOVERNANCE_COMPATIBILITY_NOTE ===

- COPE_SELECTION_RULE is deterministic and cycle-resolvable.
- Probability and risk bands move one band per cycle unless override proof is complete.
- Maladaptive escalation requires cross-cycle PRIMARY_MECHANISM continuity.
- Stabilization is cue-supported, not automatic reset.
